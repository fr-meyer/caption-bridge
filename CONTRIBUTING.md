# Contributing

Start with a non-sensitive bug report or proposal in
https://github.com/fr-meyer/caption-bridge/issues. Include the version or commit,
platform, expected behavior, and a minimal synthetic reproduction. Support and
review are best-effort. See [SECURITY.md](SECURITY.md) for sensitive reports.

Keep pull requests focused and include regression tests. Follow the locked
development setup and checks in [README.md](README.md). Report exactly which
checks ran and which did not; mocked tests are not provider or hardware proof.
Do not weaken existing CI or attended acceptance criteria.

Never commit credentials, environment files, private audio, transcripts, or
unredacted diagnostics. Use original synthetic fixtures where possible. Document
provenance and redistribution rights for third-party material, and preserve
license and attribution notices. Contributions should be compatible with the
root MIT license; separately licensed fixtures retain their own terms.
