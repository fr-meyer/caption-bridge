# Security

CaptionBridge is an early-stage project. No production security qualification,
security support window, or response-time guarantee is offered.

Do not post API keys, recordings, transcripts, account details, or unredacted
logs in public issues. If a key is exposed, revoke or rotate it with its provider.
Keep the service loopback-only and review external-provider data and cost terms.

A private reporting channel is not established by this document. For coordination,
open a minimal, non-sensitive issue at
https://github.com/fr-meyer/caption-bridge/issues asking the maintainer for a safe
reporting route. Withhold exploit details and sensitive evidence until a suitable
channel has been agreed. Do not assume a public issue is confidential.
