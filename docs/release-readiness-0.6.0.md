## Supported scope and unchanged choices

Supported distribution remains repository/CLI operation with Chromium. This
source release adds no signed/notarized installer or autostart. Normal speech
speed, buffered playback defaults and the selected providers stay unchanged;
progressive playback stays opt-in. Speed evaluation is not a validated faster
default, and unresolved provider research is not a production migration.
All eight issue and old draft dispositions remain linked in #92; keep an issue
open whenever its own human, physical or live evidence remains missing.
